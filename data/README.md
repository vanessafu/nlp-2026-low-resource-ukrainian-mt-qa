# Data Overview

## Directory structure

```
data/
├── training/
│   ├── train.jsonl                  ← combined training set (MT + QA, shuffled)
│   ├── MT/
│   │   ├── cs-uk/train.jsonl        ← cs-uk MT only
│   │   └── en-uk/train.jsonl        ← en-uk MT only
│   └── QA/train.jsonl               ← QA only
├── validation/
│   ├── validation.jsonl             ← combined validation set (MT + QA)
│   ├── MT/
│   │   ├── cz-uk/validation.jsonl   ← cz-uk MT only
│   │   └── en-uk/validation.jsonl   ← en-uk MT only
│   └── QA/validation.jsonl          ← QA only
├── test/
│   ├── MT/en-uk/test.en_uk.jsonl
│   ├── MT/cz-uk/test.cs_uk.jsonl
│   └── QA/test.jsonl
├── processed/                       ← intermediate outputs (fiction back-translation)
└── raw/                             ← original downloaded corpora
```
